何切练习室 · Windows / macOS 本地版

1. 先完整解压 ZIP，保留解压后的整个文件夹。
2. Windows：双击“启动网站-Windows.cmd”，会用默认浏览器打开练习网站。
3. macOS：双击“何切练习室.app”（麻将图标）。
4. 两种系统都可以直接双击“打开练习网站.html”离线使用，无需安装依赖。

启动图标、dist、scripts 等文件应一起保留；可移动或重命名整个文件夹。
macOS 启动器包含 Apple Silicon（macOS 12+）和 Intel（macOS 13+）版本；
更早的系统可使用通用 HTML 入口。如本机没有 Python，
会自动使用离线 HTML 入口。Windows 启动入口不依赖 Python。

练习记录保存在当前浏览器，不保存在 ZIP 内。请固定使用同一浏览器、
同一入口和文件位置；本机 HTTP 入口与直接打开 HTML 的记录不互通。
如果浏览器不允许文件页面保存记录，macOS 可使用本机 HTTP 入口；
Windows 安装了 Python 时，也可在文件夹中运行：
    python scripts/serve.py

全部 300 题、中文解析、原题与答案图、完整牌面均已包含，可离线使用。
GitHub 版包含题库制作脚本和已核对的构建数据；原 PDF 与大型 OCR 中间资料
保留在本地完整备份中，不纳入仓库。直接练习不需要这些原始资料。
